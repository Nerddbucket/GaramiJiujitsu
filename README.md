# Garami Jiu Jitsu

Official website for **Garami Jiu Jitsu** — a Brazilian Jiu Jitsu and MMA gym in Fayetteville, NC.

Train with coaches who care about your growth on and off the mat. Kids, adults, and beginners welcome.

## About

Garami Jiu Jitsu offers Brazilian Jiu Jitsu, MMA, and striking in a supportive community environment. Programs use an ECO Model that blends technique, intensity, and community so students develop skill quickly — from first class through competition.

## Tech stack

React · TypeScript · Vite · Tailwind CSS · React Router  
Deployed on GitHub Pages

## Getting started

Requires [Node.js](https://nodejs.org/) 18+.

```bash
npm install
npm run dev      # local development
npm run build    # production build → dist/
npm run preview  # preview the production build
```

Pushes to `main` deploy automatically via GitHub Actions (`.github/workflows/deploy.yml`).
